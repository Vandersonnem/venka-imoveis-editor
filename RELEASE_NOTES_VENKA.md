Venka Imóveis Editor é a versão com identidade da Venka Imóveis do editor aberto Concat, criado por Jareer/jub0t e contribuidores. Licença AGPL-3.0-or-later; os avisos originais e o código correspondente acompanham a distribuição.

- Identidade Venka, nome próprio e bundle ID `com.venkaimoveis.editor`.
- Edição local, visual adaptável para celular/PC e projeto vertical 9:16.
- Windows x64, macOS Apple silicon, Android arm64 e iOS/iPadOS arm64.
- O IPA usa sideload e precisa ser re-assinado pelo usuário em AltStore/Sideloadly.
- Sem certificados de produção configurados, Windows não tem Authenticode e macOS recebe assinatura ad-hoc, sem notarização.

Antes de publicar este rascunho, registre aqui os testes reais de instalação, importação, edição, exportação e reprodução feitos para o commit indicado em VENKA_RELEASE.json. Os testes de inicialização do CI e o simulador não substituem a revisão no aparelho físico.
